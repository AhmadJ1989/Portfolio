# my_website

موقع شخصي احترافي لمطوّر ذكاء اصطناعي بصفحات متعددة ودعم ثلاث لغات: العربية، الإنجليزية، والألمانية.

## الصفحات
- الصفحة الرئيسية: `index.html`
- من أنا: `about.html`
- الخدمات: `services.html`
- المشاريع: `projects.html`
- تواصل: `contact.html`

## اللغات
يمكنك التبديل بين اللغات عبر أزرار EN / DE / AR أعلى الصفحة. سيتم حفظ اللغة المختارة تلقائيًا.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح أو استخدم خادمًا ثابتًا:

```bash
python -m http.server 8080
```

ثم زر:
`http://localhost:8080/my_website/index.html`
